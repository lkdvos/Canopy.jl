# Canopy.jl

A [TensorKit.jl](https://github.com/Jutho/TensorKit.jl)-based library for tensor
network states on arbitrary graphs, targeting belief-propagation and
simple-update algorithms.

!!! warning "Status: early development"
    The API is unstable and changes frequently.

## Installation

```julia
using Pkg
Pkg.add(url = "https://github.com/lkdvos/Canopy.jl")
```
