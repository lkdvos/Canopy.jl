# Canopy

[![Build Status](https://github.com/lkdvos/Canopy/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/lkdvos/Canopy/actions/workflows/CI.yml?query=branch%3Amain)

A [TensorKit.jl](https://github.com/Jutho/TensorKit.jl)-based library for tensor network states on arbitrary graphs, targeting belief-propagation and simple-update algorithms.

See `docs/design.md` for the current data-structure design.

> **Status:** early development. The API is unstable and changes frequently.
